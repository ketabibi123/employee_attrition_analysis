# Employee Attrition Analysis
Python-based analysis of employee attrition patterns using data analysis and machine learning. 
The goal of the project was to identify patterns associated with employee turnover and explore how data analysis and machine learning can be used to better understand employee attrition.
Tools used: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
This project was developed as a group project. My contributions to the project were data visualization and machine learning. I worked on exploring and presenting patterns in the data through visualizations and contributed to the development and evaluation of machine-learning models used in the analysis.
